Install vela kubectl plugin can help you to ship applications more easily!

## Installation

You can install kubectl plugin `kubectl vela` by:

<Tabs
className="unique-tabs"
defaultValue="krew"
values={[
    {label: 'Krew', value: 'krew'},
    {label: 'Script', value: 'script'},
]}>
<TabItem value="krew">

1. [Install and set up](https://krew.sigs.k8s.io/docs/user-guide/setup/install/) Krew on your machine.
2. Discover plugins available on Krew:

```shell
kubectl krew update
```

3. install kubectl vela:

```shell script
kubectl krew install vela
```

The Krew index only carries amd64 builds. On Apple silicon or another arm64 machine, use the release page in the Script tab.

</TabItem>
<TabItem value="script">

**macOS/Linux**

```shell script
curl -fsSl https://kubevela.io/script/install-kubectl-vela.sh | bash
```

The script installs the newest release. While a pre-release is the newest release, it stops with `Failed to get latest release tag`; download the `kubectl-vela` archive for your platform (for example `kubectl-vela-v<version>-linux-amd64.tar.gz`) from the [release page](https://github.com/kubevela/kubevela/releases) instead, extract it, and put the `kubectl-vela` binary inside on your `PATH`. Kubectl finds it there by itself.

</TabItem>
</Tabs>

## Usage

```shell
$ kubectl vela -h
A Highly Extensible Platform Engine based on Kubernetes and Open Application Model.

Usage:
  kubectl vela [flags]
  kubectl vela [command]

```
