## Summary

Reverts `apply-component` namespace support and removes an unused controller option.

## Breaking changes

- **`apply-component` namespace removed.** Reverts "`apply-component` supports namespace" from v1.9.5; remove `namespace` from any `apply-component` step that sets it ([#6247](https://github.com/kubevela/kubevela/pull/6247)).

## Bug fixes

- The unused `EnableCompatibility` controller option is removed while organising the application handler; controller flags are unchanged ([#6254](https://github.com/kubevela/kubevela/pull/6254)).
