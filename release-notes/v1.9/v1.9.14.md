## Summary

Security fix for the Terraform remote configuration loader. Everyone still on v1.9 should take it, and plan to move to a supported version.

## Bug fixes

- The Terraform remote configuration loader no longer reads unbounded input ([GHSA-fmgp-q6jx-gg3x](https://github.com/kubevela/kubevela/security/advisories/GHSA-fmgp-q6jx-gg3x), [#7192](https://github.com/kubevela/kubevela/pull/7192)).
- `last-applied-configuration` is preserved for resources shared between Applications ([#7000](https://github.com/kubevela/kubevela/pull/7000)).
