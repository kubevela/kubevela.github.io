## Summary

`vela install` switches between the old and new registry, and the applicator change from v1.9.0 is reverted. Take it if you install with `vela install` or run v1.9.0 to v1.9.2.

## Behaviour changes

- Reverts "support applicator applying resources and update status" ([#6030](https://github.com/kubevela/kubevela/pull/6030)) from v1.9.0 ([#6182](https://github.com/kubevela/kubevela/pull/6182)).
- `vela install` switches between the old and new registry ([#6173](https://github.com/kubevela/kubevela/pull/6173)).

## Bug fixes

- `vela top` renders correctly ([#6174](https://github.com/kubevela/kubevela/pull/6174)).
