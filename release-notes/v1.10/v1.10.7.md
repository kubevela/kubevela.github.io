## Summary

Component removals are persisted and reflected in status.

## Bug fixes

- Removing a component from an Application is persisted and reflected in status ([#7029](https://github.com/kubevela/kubevela/pull/7029)).
- Application validation no longer fails when a component uses traits together with workflow `inputs` and `outputs`, and the structured Application log includes the component type ([#7040](https://github.com/kubevela/kubevela/pull/7040)).
