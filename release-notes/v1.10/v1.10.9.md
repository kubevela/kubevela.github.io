## Summary

Security fix for the Terraform remote configuration loader. Everyone on v1.10 should upgrade.

## Bug fixes

- The Terraform remote configuration loader no longer reads unbounded input ([GHSA-fmgp-q6jx-gg3x](https://github.com/kubevela/kubevela/security/advisories/GHSA-fmgp-q6jx-gg3x), [#7191](https://github.com/kubevela/kubevela/pull/7191)).
- `import` statements in `status.details` compile correctly ([#7057](https://github.com/kubevela/kubevela/pull/7057)).
