## Summary

Fixes VelaQL view validation, which in v1.10.0 rejected valid views. Take it if you run v1.10.0.

## Bug fixes

- VelaQL view validation only checks that a view has a `status` or `export` field, and no longer fails when that field cannot be rendered before the view runs ([#6687](https://github.com/kubevela/kubevela/pull/6687)).
