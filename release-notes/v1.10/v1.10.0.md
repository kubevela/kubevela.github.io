## Summary

v1.10 moves definition rendering to the CueX engine on CUE v0.9.2, adds semantic versions for
definitions and CUE required fields, and upgrades to Go 1.22 and the Kubernetes v0.29 libraries.

## Compatibility

| Component | Version |
| --- | --- |
| Kubernetes | Tested with v1.29 |
| Go | 1.22.0 |
| CUE | v0.9.2 |
| Kubernetes client libraries | `k8s.io/client-go` v0.29.2, `controller-runtime` v0.17.6 |
| Upgrade from | v1.9.x; see the [upgrade guide](/upgrade-guides/v1.10/) |

## Breaking changes

- **CUE v0.5.0 to v0.9.2 and the CueX engine.** Definitions now render with the CueX engine
  ([#6575](https://github.com/kubevela/kubevela/pull/6575)). Check your custom definitions against
  the new CUE version before upgrading; see the
  [upgrade guide](/upgrade-guides/v1.10/#check-your-definitions).
- **`ref-objects` needs `group`.** When a `ref-objects` component references a resource outside
  the default groups (`core.oam.dev` and the empty group), set its `group` field; see
  [Distribute Reference Objects](/docs/end-user/components/ref-objects/).
- **`--leader-election-resource-lock` is removed.** controller-runtime v0.17 supports only Lease
  locks. Remove the flag from any custom controller arguments, or the controller fails to start.

## CRD changes

- New CRD `packages.cue.oam.dev` (`Package`), for external CueX packages.
- `ComponentDefinition`, `TraitDefinition`, `PolicyDefinition` and `WorkflowStepDefinition` add
  `spec.version`, a semantic version for the definition
  ([#6648](https://github.com/kubevela/kubevela/pull/6648)).

Apply the CRDs before `helm upgrade`.

## New features

- Semantic versions for definitions, so an Application can pin a definition version
  ([#6648](https://github.com/kubevela/kubevela/pull/6648)).
- CUE required fields (`!`) in definition parameters
  ([#6622](https://github.com/kubevela/kubevela/pull/6622)).
- `securityContext` and `podSecurityContext` traits
  ([#6666](https://github.com/kubevela/kubevela/pull/6666)).
- New CueX providers ([#6599](https://github.com/kubevela/kubevela/pull/6599)).

## Bug fixes

- The `affinity` trait keeps `namespaces` in `requiredDuringSchedulingIgnoredDuringExecution`.
- The `vela-cli` workflow step renders volumes correctly.
- Startup no longer logs auto `GOMAXPROCS` settings.
- Build labels and annotations are included in image metadata.
