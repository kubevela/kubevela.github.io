## Summary

Fixes the v1.10.4 regression with imports and packages in status validation, and a definition access issue. Upgrade from v1.10.4 straight away.

## Breaking changes

- **Definitions in `vela-system` need permission.** Only with `authorization.definitionValidationEnabled=true` (off by default): namespace admins can no longer use definitions in `vela-system` without explicit permission. Grant it as described in [Definition RBAC](/docs/v1.10/platform-engineers/auth/definition-rbac/) ([#6967](https://github.com/kubevela/kubevela/pull/6967)).

## Bug fixes

- Imports and packages in status validation work again ([#6971](https://github.com/kubevela/kubevela/pull/6971)).
