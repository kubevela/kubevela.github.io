### 1. Kubernetes Requirements:

- Kubernetes cluster `>= v1.25`. KubeVela 1.12 is tested with Kubernetes v1.37 only. v1.25 is the lowest version that can accept the `ConfigTemplate` CRD, whose validation rules use CEL; versions between v1.25 and v1.36 are not tested. The Kubernetes versions each release supports are in the [release notes](../release-notes/overview.md#supported-versions).

KubeVela relies on Kubernetes as a control plane. The control plane could be any managed Kubernetes offering or your own clusters, such as:

- Alibaba Cloud [ACK Service](https://www.aliyun.com/product/kubernetes)
- AWS [EKS Service](https://aws.amazon.com/cn/eks)
- Azure [AKS Service](https://azure.microsoft.com/en-us/services/kubernetes-service)
- Google [GKE Service](https://cloud.google.com/kubernetes-engine)
- Rancher [K3s](https://rancher.com/docs/k3s/latest/en/quick-start/) or [RKE](https://github.com/rancher/rke/releases)

### 2. Install KubeVela CLI {#install-vela-cli}

KubeVela CLI provides an easy way to engage and manage your application delivery in command lines.

`vela install` installs the KubeVela version that matches your CLI, so install the CLI version you want first.

<TabItem value="script">

**MacOS/Linux**

The script installs the latest stable release unless you give it a version. For this release:

```shell
curl -fsSl https://kubevela.io/script/install.sh | bash -s 1.12.0
```

**Windows**

:::note
Only the official release version is supported.
:::

```shell
powershell -Command "iwr -useb https://kubevela.io/script/install.ps1 | iex"
```

</TabItem>
<TabItem value="homebrew">

**MacOS/Linux**

Homebrew installs the latest official release only. Update your brew first:

```shell
brew update
```

Then install KubeVela CLI:

```shell
brew install kubevela
```

</TabItem>
<TabItem value="download">

- Download the `vela` binary for your platform from the [releases page](https://github.com/kubevela/kubevela/releases).
- Unzip it and move it onto your `$PATH`:

```shell
sudo mv ./vela /usr/local/bin/vela
```

:::note
On macOS, the first run may be blocked with a warning that "vela" can't be opened because the developer can't be verified. Remove the quarantine flag:

```shell
xattr -d com.apple.quarantine /usr/local/bin/vela
```

Or open **System Settings -> Privacy & Security** and click **Allow Anyway**.
:::
</TabItem>
</Tabs>

<details>
  <summary>Other ways: asdf and Docker</summary>

**asdf (MacOS/Linux)**

If you are using the [asdf version manager](https://asdf-vm.com/), you can install `vela` with:

```shell
# Add the vela plugin for asdf
asdf plugin add vela

# List all installable versions
asdf list-all vela

# Install the desired version (could be "latest")
asdf install vela <version>

# set it as the global version, unless a project declares it otherwise locally
asdf global vela <version>
```

**Docker**

The CLI is also published as the `oamdev/vela-cli` image:

```shell
docker run --rm -it -v ~/.kube:/root/.kube oamdev/vela-cli version
```

Refer to [using Vela CLI docker image](../platform-engineers/system-operation/vela-cli-image.md) for more usage.

</details>

<TabItem value="helm">

If you are helm user, you can also use helm to install KubeVela core:

:::note
helm v3.6.3+ required
:::

```shell
helm repo remove kubevela 2>/dev/null || true
helm repo add kubevela https://kubevela.github.io/charts
helm repo update
helm install --create-namespace -n vela-system kubevela kubevela/vela-core --version 1.12.0 --wait
```

Without `--version`, Helm skips pre-releases and installs the latest stable chart.

Keep the release name `kubevela`: later guides upgrade it by that name.

</TabItem>
</Tabs>

### 4. Check it's running

```shell
vela version
```

```console
CLI Version: 1.12.0
Core Version: 1.12.0
GitRevision: git-...
GolangVersion: go1.27.1
```

```shell
kubectl get pods -n vela-system
```

```console
NAME                                         READY   STATUS    RESTARTS   AGE
kubevela-cluster-gateway-5bff6d564d-rhkp7    1/1     Running   0          2m
kubevela-vela-core-6dc4d47c6c-2xnhn          1/1     Running   0          2m
```

If `Core Version` is empty, the core isn't installed in `vela-system`.

### 5. Install VelaUX

VelaUX is a dashboard for KubeVela. It is a web application that runs in your cluster, and you reach it with your browser.

VelaUX is optional. To add it, run `vela addon enable velaux`, then `vela port-forward addon-velaux -n vela-system 8000:8000`. The addon is VelaUX 1.9.5; see [VelaUX](../reference/addons/velaux.md) for what it can't show on 1.12.
