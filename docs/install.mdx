---
title: Installation Overview
---

How you install KubeVela depends on whether you already have a Kubernetes cluster.

### No cluster yet?

Create one with k3d or kind (one command) and install KubeVela into it. With [k3d](https://k3d.io/), which needs Docker:

```shell
# 1. Create a local cluster
k3d cluster create kubevela

# 2. Install the vela CLI, pinned to this release
curl -fsSl https://kubevela.io/script/install.sh | bash -s 1.12.0

# 3. Install KubeVela into the cluster
vela install
```

With [kind](https://kind.sigs.k8s.io/), the first step is `kind create cluster --name kubevela`; the rest is the same. `vela install` installs the KubeVela version that matches the CLI. See [Kubernetes Cluster](./installation/kubernetes.mdx) for the other ways to get the CLI and for installing with Helm.

:::caution
[VelaD](https://github.com/kubevela/velad), the single-binary [standalone install](./installation/standalone.mdx), ships KubeVela 1.9.5. Features documented here from later releases are not available in it, so use the steps above to try KubeVela 1.12.
:::

### Already have a Kubernetes cluster?

- [Kubernetes Cluster](./installation/kubernetes.mdx): install KubeVela into an existing cluster. Use a managed Kubernetes service for production.

:::tip
- For upgrading from existing KubeVela control plane, please read the [upgrade guide](./upgrade-guides/overview.mdx).
:::
