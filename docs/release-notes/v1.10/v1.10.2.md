## Summary

Adds controller metrics and switches the CLI to the new Helm repository URL.

## Breaking or behaviour changes

- `vela install` and the CLI use the new Helm repository URL, `https://kubevela.github.io/charts` ([#6694](https://github.com/kubevela/kubevela/pull/6694)).

## Helm chart and flag changes

- `core.metrics.enabled` and `core.metrics.serviceMonitor.*` expose vela-core metrics through a ServiceMonitor ([#6650](https://github.com/kubevela/kubevela/pull/6650)).
- `multicluster.clusterGateway.serviceMonitor.*` adds a ServiceMonitor for cluster-gateway.

## Bug fixes

- Orphan resources are no longer skipped when they should be deleted ([#6700](https://github.com/kubevela/kubevela/pull/6700)).
- Workflow outputs are compatible again after the workflow update ([#6701](https://github.com/kubevela/kubevela/pull/6701)).
