## Summary

Fixes for `status.details`, apply-once resources and applied resources.

## Breaking or behaviour changes

- `status.details` supports dynamic keys, with an option to turn off its validation ([#7062](https://github.com/kubevela/kubevela/pull/7062)).

## Bug fixes

- Externally deleted apply-once resources are not recreated on reconcile ([#7054](https://github.com/kubevela/kubevela/pull/7054)).
- `appliedResources` is rebuilt from the ResourceTracker instead of being filtered by name ([#7086](https://github.com/kubevela/kubevela/pull/7086)).
- `debug-webhook-setup.sh` works with k3d on macOS with Docker Desktop.
