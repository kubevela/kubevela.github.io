## Summary

**Deprecated: don't use this release.** It contains an unintended breaking change for components that use `import` statements. Upgrade to [v1.10.5](./v1.10.5.md) or later instead.

## Breaking or behaviour changes

- Enhanced status reporting and consolidated health and status, with native CUE in `healthPolicy` and `customStatus` ([#6828](https://github.com/kubevela/kubevela/pull/6828), [#6859](https://github.com/kubevela/kubevela/pull/6859), [#6860](https://github.com/kubevela/kubevela/pull/6860)).
- Components can gate on `dependsOn` ([#6854](https://github.com/kubevela/kubevela/pull/6854)).
- The webhook rejects unknown custom resources in outputs ([#6932](https://github.com/kubevela/kubevela/pull/6932)).
- `vela up` and the CLI's namespace handling behave like `kubectl` ([#6805](https://github.com/kubevela/kubevela/pull/6805), [#6809](https://github.com/kubevela/kubevela/pull/6809)).
- CRDs change: `ApplicationRevision`, `Application` and the definition CRDs add status `details`. Apply the CRDs before `helm upgrade`.

## Helm chart and flag changes

- New feature gates, all Alpha and off: `ValidateDefinitionPermissions`, `EnableApplicationStatusMetrics` and `ValidateResourcesExist`.
- New flag `--dev-logs` and chart value `devLogs` for colourised development logs.
- New chart values `featureGates.enableApplicationStatusMetrics`, `featureGates.validateResourcesExist` and `authorization.definitionValidationEnabled`.
- `k8s.io/client-go` `v0.29.2` → `v0.31.10` and `controller-runtime` `v0.17.6` → `v0.19.7` ([#6837](https://github.com/kubevela/kubevela/pull/6837)).

## New features

- Application status metrics and structured logs ([#6857](https://github.com/kubevela/kubevela/pull/6857)).
- Definition permissions are validated when an Application is created ([#6876](https://github.com/kubevela/kubevela/pull/6876)).

## Bug fixes

- The webhook TLS `caBundle` survives a failed Helm upgrade ([#6919](https://github.com/kubevela/kubevela/pull/6919)).
- The `storage` trait handles hostPath volumes, and `vela def render` exits non-zero on error.

## Known issues

- Components whose templates use `import` statements fail. Fixed in [v1.10.5](./v1.10.5.md).
