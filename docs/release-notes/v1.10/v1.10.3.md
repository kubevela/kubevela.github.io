## Summary

Adds a StatefulSet component, CueX in component and trait templates and signed releases, and builds with Go 1.23.8.

## Breaking or behaviour changes

- The `task` component can run once to completion ([#6733](https://github.com/kubevela/kubevela/pull/6733)).
- Required CUE parameters, including dynamic sources, are validated fail-fast ([#6774](https://github.com/kubevela/kubevela/pull/6774)).

## Helm chart and flag changes

- `--enable-external-package-for-default-compiler` and `--enable-external-package-watch-for-default-compiler` move to the shared CueX package; names and defaults are unchanged.
- Chart `tolerations`, `nodeSelector` and `affinity` accept any valid value ([#6771](https://github.com/kubevela/kubevela/pull/6771)).

## New features

- `statefulset` component ([#6638](https://github.com/kubevela/kubevela/pull/6638)) and CueX in component and trait templates ([#6720](https://github.com/kubevela/kubevela/pull/6720)).
- Cluster tokens can come from an `AuthInfo.Exec` command ([#6721](https://github.com/kubevela/kubevela/pull/6721)).
- Releases are signed and ship SBOMs and SLSA provenance ([#6749](https://github.com/kubevela/kubevela/pull/6749)).

## Bug fixes

- Detached clusters are removed from ResourceTrackers, and applications with a topology policy are updated on cluster join.
- Definition revisions are deleted again ([#6738](https://github.com/kubevela/kubevela/pull/6738)).
- The `startup-probe` trait no longer duplicates `tcpSocket`, and `webservice` defines resource requests and limits.
- Go `1.22.0` → `1.23.8` ([#6767](https://github.com/kubevela/kubevela/pull/6767)) and vulnerable packages upgraded.
