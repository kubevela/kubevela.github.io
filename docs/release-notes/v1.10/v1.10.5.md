## Summary

Fixes the v1.10.4 regression with imports and packages in status validation, and a definition access issue. Upgrade from v1.10.4 straight away.

## Breaking or behaviour changes

- Namespace admins can no longer use definitions in `vela-system` without explicit permission ([#6967](https://github.com/kubevela/kubevela/pull/6967)).

## Bug fixes

- Imports and packages in status validation work again ([#6971](https://github.com/kubevela/kubevela/pull/6971)).
