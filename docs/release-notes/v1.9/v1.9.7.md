## Summary

Adds `vela workflow list`, `apply-component` namespace support and webhook validation of CUE templates.

## Breaking or behaviour changes

- The webhook validates the CUE template of definitions, and policy definitions ([#6355](https://github.com/kubevela/kubevela/pull/6355)).

## Helm chart and flag changes

- The validating webhook uses the current TraitDefinition API versions ([#6352](https://github.com/kubevela/kubevela/pull/6352)).

## New features

- `vela workflow list` lists all workflows ([#6326](https://github.com/kubevela/kubevela/pull/6326)).
- `apply-component` supports a namespace ([#6248](https://github.com/kubevela/kubevela/pull/6248)).
- Addons can carry an annotation ([#6256](https://github.com/kubevela/kubevela/pull/6256)), and the controller accepts unknown flags ([#6303](https://github.com/kubevela/kubevela/pull/6303)).

## Bug fixes

- The `container-ports` trait keeps the port name ([#6274](https://github.com/kubevela/kubevela/pull/6274)) and the `gateway` trait sets it ([#6329](https://github.com/kubevela/kubevela/pull/6329)).
- Addon dependencies with a `v`-prefixed version resolve ([#6316](https://github.com/kubevela/kubevela/pull/6316)).
- `vela show` formats Markdown output correctly ([#6356](https://github.com/kubevela/kubevela/pull/6356)).
- terraform-controller v0.8.0 ([#6363](https://github.com/kubevela/kubevela/pull/6363)).
