Scan all definitions and their revision history for CUE incompatibilities

### Synopsis

Scans every definition across all namespaces for CUE syntax incompatible
with the current KubeVela version, grouped by definition with the affected
DefinitionRevisions listed under each.

Use --latest-revision-only to skip revision history and check only the
current live definition.

```
vela def compatibility-check definitions [flags]
```

### Examples

```
# Scan all definitions and all their historical revisions
vela def compatibility-check definitions

# Scan only the current live definition (skip revision history)
vela def compatibility-check definitions --latest-revision-only

# Output as YAML
vela def compatibility-check definitions -o yaml
```
