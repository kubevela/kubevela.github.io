Scaffold a new crate.

### Synopsis

Scaffold a valid, ready-to-edit crate directory with placeholder content and TODO markers, so you start from a working skeleton instead of assembling the layout by hand.

```
vela crate init <name> [flags]
```

### Examples

```
  Scaffold a crate named s3 in the current directory:
	vela crate init s3

  Scaffold under a chosen directory:
	vela crate init s3 --path ./crates
```
