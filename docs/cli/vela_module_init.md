Scaffold a new module.

### Synopsis

Scaffold a valid, ready-to-edit module directory with placeholder content and TODO markers, so you start from a working skeleton instead of assembling the layout by hand.

```
vela module init <name> [flags]
```

### Examples

```
  Scaffold a module named s3 in the current directory:
	vela module init s3

  Scaffold under a chosen directory:
	vela module init s3 --path ./modules
```

### Options

```

      --path string   Directory to create the <name>/ module directory under. (default ".")
```
